VERDICT: CHANGES REQUIRED

Required changes

1. **D6/D7: resolve who may initiate hardware I/O.** D6 permits free agent-driven reads; D7 says “agents never open … the ENET link” and “hardware runs are maintainer-run.” Calling MCP would still cause hardware I/O. Nothing enforces the distinction (`crates/diagwire/src/lib.rs:36`, `crates/cli/src/main.rs:47,60,84`). **Fix:** define whether agent-initiated live operations are prohibited or permitted through a maintainer-controlled broker. Specify the enforcement boundary, including discovery and CLI execution.

2. **D6/replay 6: specify an enforceable consent contract.** Rejecting model-supplied booleans is necessary but insufficient. The record leaves consent binding, reuse, expiration and retries undecided. A raw transport remains publicly reachable through the re-export (`crates/diagwire/src/lib.rs:7`, `crates/hsfz/src/lib.rs:143`). **Fix:** either exclude clear from v0 or require human approval bound to vehicle/session, ECU, operation and parameters, consumed once. Cover every hardware entry point. CLI-only does **not** remove replay 6 unless an agent cannot invoke that CLI.

3. **Replays 1–2/first slice: decide transaction isolation and bounded completion.** The stale-response and chatter findings are correct (`crates/diagwire/src/lib.rs:49-58,75-95`), but D1/D2 merely enable a fix. Even single-ECU `read_dtcs` can accept a late answer after a previous timeout. **Fix:** require one outstanding transaction, an absolute operation deadline, response address/service/subfunction validation, and connection disposal after ambiguous timeout or cancellation. Specify pending/partial outcomes; disable functional scanning until its per-ECU completion policy exists.

4. **Replays 1 and 4: “handled” overstates timeout coverage.** The ACK deadline starts **after** an unbounded `write_all`; alive replies also use unbounded writes (`crates/hsfz/src/lib.rs:146-150,156,195`). An alive response can therefore stall beyond the purported deadline. **Fix:** make the deadline cover sending and alive handling, and discard the connection after an interrupted write. Describe the present handling as partial.

5. **Replay 3: preservation is plausible; recovery is undecided.** Completed reads are retained (`crates/hsfz/src/lib.rs:209-218`), but malformed input poisons the buffer indefinitely. No decision requires termination or recovery. **Fix:** require closing the connection on malformed framing; add a fake-stream split/read-timeout acceptance scenario. Resynchronization is unnecessary for v0.

6. **D3/D6 and authority register: qualify unsupported protocol facts.** The register declares functional address scope, clear bytes and DTC status meanings unverified, yet D6 asserts “Reads don't change the car,” that clear erases freeze-frame evidence, and that `0xDF` reaches every ECU. Code cannot establish those semantics (`crates/uds/src/lib.rs:34-35`; `crates/diagwire/src/lib.rs:10-11`). **Fix:** label these assumptions and gate exposed operations on checked authority. Define a reviewed read-operation allowlist rather than treating arbitrary jobs as safe because they are called reads.

7. **First slice steps 5–6: narrow what a capture verifies.** A fake returning captured replies proves parsing against that example; it does not prove outgoing requests, ACK validation, idle behavior or all control words. Step 5 only explicitly compares the DTC list. **Fix:** require the fake to assert outgoing bytes and expected exchanges; update only register claims actually exercised. Include the ISO clause check required by D3 before claiming UDS conformance.

8. **D4/D8/first slice step 2: settle evidence handling before committing captures.** D8 requires a redaction policy, but the slice proceeds to commit without defining it. D4 requires revision provenance, omitted from step 2’s stamp. **Fix:** require provenance and redaction review before commit, document transformations, and retain a private original reference. Distinguish permitted decoded diagnostic evidence from prohibited copied proprietary tables.

9. **Replay 8: qualify error retention and make rejection a decision.** The parser rejects the malformed record length, but a later response from the same ECU overwrites that error (`crates/uds/src/lib.rs:153-155`; `crates/diagwire/src/lib.rs:95`). Thus “the error stays attached” is conditional. **Fix:** state this limitation and require v0 to report malformed responses as errors, without presenting salvaged records as a complete fault list.

10. **D1/D8/replay 5: correct factual overstatements.**
    - Fixed port 6801 does not inherently prevent parallel tests; a shared listener can dispatch connections. The actual limitation is the missing injectable stream (`crates/hsfz/src/lib.rs:119-140`).
    - `ds2::decode` rejects checksum-invalid telegrams, not corrupted echoes generally (`crates/ds2/src/lib.rs:49-69`). Echo handling remains absent.
    - D8’s repository inventory omits license files and the author note.
    - “Every protocol constant comes from memory” is not established by code; HSFZ documentation instead names public reverse-engineering notes (`crates/hsfz/src/lib.rs:7-9`).
    
    **Fix:** narrow these statements to observable implementation facts and attribute origin claims to the author.

Optional suggestions

2. **D4:** distinguish the general fixture loader from the conformance gate. Characterization fixtures can remain loadable while being ineligible for conformance.
3. **D2:** replace “would need a wall-clock test” with “cannot use Tokio’s paused clock unchanged.” An injected clock is another option.
